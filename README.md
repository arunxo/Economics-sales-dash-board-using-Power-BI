# 📊 E-commerce Sales Performance Dashboard – Power BI

A dynamic and interactive Power BI report analyzing e-commerce sales data to uncover actionable insights across states, categories, payment modes, and customers.

## 🧾 Overview

This dashboard was built to help businesses make data-driven decisions for optimizing their e-commerce strategy. It offers a comprehensive view of sales, profit, average order value, and customer behavior segmented by geography, category, and payment method.

## 📌 Key Features

- 💰 **Sales KPIs**: Total Revenue, Quantity Sold, Profit, AOV (Average Order Value)
- 📍 **Geographic Breakdown**: State-wise sales comparison
- 📦 **Product Insights**: Top categories and sub-categories by quantity and profit
- 🧾 **Customer Insights**: High-value customers by purchase amount
- 🧾 **Payment Trends**: Usage distribution across payment modes (UPI, COD, Cards, EMI)
- 📆 **Time Series**: Monthly profit trends with quarter filter

## 🧠 Tools Used

- Power BI (Desktop)
- Excel (data preprocessing)
- DAX (Data Analysis Expressions for calculations)

## 📈 Insights Derived

- **Maharashtra** leads in revenue among all states.
- **Clothing** dominates product sales, accounting for 66% of quantity.
- **Cash on Delivery (COD)** remains the most preferred payment method (44%).
- **November** outperforms other months in quarterly profit analysis.
- Sub-category **Printers** yields the highest profit margin.
